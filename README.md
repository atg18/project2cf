# Collaborative Text Editor

A real-time collaborative text editor inspired by **Google Docs**, built using:

* **React** for the frontend
* **Node.js** + **Express** for the backend
* **Vite** for fast development and optimized builds
* **WebSockets** for live collaboration
* **Quill.js** as the rich text editor

This project allows multiple users to edit the same document simultaneously, with changes updating in real-time across all connected clients.

## Features

* Real-time collaborative editing
* Rich text formatting 
* Auto-saving and live updates
* Multiple users editing the same document
* Fast refresh and optimized bundling with Vite

## Tech Stack

* **Frontend:** React, Vite, Quill
* **Backend:** Node.js, Express, Socket.io
* **Collaboration:** WebSockets for bi-directional communication

## Getting Started

1. Clone the repository
2. Install dependencies in both `/client` and `/server`
3. Run the development servers
